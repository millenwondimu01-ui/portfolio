Artifact 5

Responsible AI Redesign of a Fraud Detection System

This group project analyzes a machine learning fraud detection system and redesigns it using responsible AI principles across the full system lifecycle.

Description

ObjectiveEvaluate how a fraud detection system can identify suspicious transactions while reducing false declines, protecting customer data, and supporting fair decisions.
Focus areasStakeholders, data quality, bias entry points, model validation, privacy, fairness, monitoring, human oversight, and governance.

Process

Our group examined the system from the first transaction record through deployment and ongoing monitoring. My section focused on bias entry points and safeguards within the data audit. I reviewed how customer history, location and device signals, fraud labels, merchant information, older records, transaction amounts, and payment methods could cause legitimate activity to appear suspicious. I then identified safeguards such as verification options, stronger label review, updated training data, and using several risk signals instead of relying on one factor.

Value Proposition of the Artifact

Unique value

This artifact shows that machine learning performance should not be judged by accuracy alone. A useful fraud detection system must also consider false positives, customer inconvenience, privacy, subgroup impacts, changing fraud patterns, and the role of human review.

Relevance

The project is relevant to cybersecurity, data analytics, privacy, GRC, and AI governance roles. It demonstrates my ability to connect technical model decisions with real business risks, ethical concerns, and practical safeguards.
